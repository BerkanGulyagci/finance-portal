# Proje Dökümanları

Bu klasör, projenin ayrıntılı mühendislik dökümanlarını içerir:

| Döküman | Dosya | İçerik |
|---|---|---|
| **Analiz Dökümanı (SRS)** | `Finans_Portali_Analiz_Dokumani.pdf` | Yazılım Gereksinim Spesifikasyonu — iş/kullanıcı gereksinimleri, fonksiyonel (FR) ve fonksiyonel olmayan (NFR) gereksinimler, veri/arayüz gereksinimleri, kabul kriterleri (ISO/IEC/IEEE 29148, ISO/IEC 25010). |
| **Teknik Analiz Dökümanı (SDD)** | `Finans_Portali_Teknik_Analiz_Dokumani.pdf` | Yazılım Tasarım Tanımı — mimari (C4 modeli), backend/frontend/veri/API/güvenlik/dağıtım/gözlemlenebilirlik tasarımı, mimari kararlar (ADR), riskler, doğrulama (IEEE 1016, ISO/IEC/IEEE 42010, OWASP ASVS). |

Bu dökümanlara ana [README](../README.md#detaylı-dökümantasyon) dosyasından da erişilebilir.
